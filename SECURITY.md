# Security Policy

## 🛡️ PhishShield AI Threat Disclosure & Reporting

Security and accuracy are at the core of **PhishShield AI**. If you discover a vulnerability, bypass technique, or false positive/negative in our heuristic, URL inspection, or Laya System-1 detection engine, we appreciate your help in responsibly disclosing it.

### Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

### Reporting a Vulnerability or Evasion Bypass

- **Email**: Send detailed threat vectors or bypass logs to `yahunsewkidus@gmail.com`.
- **GitHub Issues**: For non-sensitive false positives (e.g. an authentic domain incorrectly flagged), feel free to open a GitHub Issue with the sample URL or headers.
- **Response Time**: We strive to review and acknowledge all disclosures within 48 hours.

Thank you for helping keep the web safe!

Interactive Phishing & Malicious Link Test Lab

This test bench contains realistic phishing techniques, homograph domain attacks, typosquats, and dynamic link injection vectors. Use this page to verify that the PhishShield Browser Extension flags malicious links with pulsing badges, blocks deceptive clicks, and avoids false alarms on safe links.

1 Inspect links visually: Malicious links should display red ⚠️ PHISHING LINK: DO NOT TOUCH badges.

🔡 Category 1: IDN Homoglyph & Cyrillic Spoofs
High Risk

These links replace Latin characters with identical-looking Cyrillic characters (e.g. Cyrillic 'а', 'о', 'р') that register as entirely different domains in DNS.

PayPal Spoof (Cyrillic 'а' replacing Latin 'a'): http://pаypal.com/signin-verification True Host: xn--pypal-43a.com
Google Spoof (Cyrillic 'о' characters): http://gооgle.com/password-reset True Host: xn--ggle-q50aa.com
Apple ID Spoof (Cyrillic 'е'): http://applе.com/icloud-unlock True Host: xn--appl-e1a.com
⌨️ Category 2: Typosquatting & Brand Impersonation
High Risk

Substitutions ('1' for 'l', '0' for 'o') or combining trusted brand names with urgency keywords (e.g., paypal-security-update).

Substituted Letter Typosquat (paypa1 with number 1): http://paypa1-security.xyz/login.php Brand targeted: PayPal
Combosquatting Brand Extension: http://chase-security-verify.top/restore-access Brand targeted: Chase Bank
Netflix Billing Scam: http://netfl1x-account-update.club/signin Brand targeted: Netflix
🎭 Category 3: Deceptive Anchor Text (The "Trojan" Link)
Deceptive

The visible text looks like a trusted domain (e.g. google.com), but the underlying href destination points to an attacker-controlled server.

Visible text claims Google, href leads elsewhere: https://www.google.com/accounts/security-check Hidden Destination: credential-stealer-host.net
Visible text claims Bank of America: https://www.bankofamerica.com/login Hidden Destination: unauthorized-phish.ru
Visible text claims GitHub Security: https://github.com/settings/security Hidden Destination: attacker-harvest.click
🌐 Category 4: Raw IP Hosts & '@' Deception
High Risk

Phishing using raw IP addresses, high-risk TLDs (.zip, .top), or URL credential spoofing via the @ character.

Raw IPv4 Hostname with Banking Path: http://192.168.1.100/banking-login.php Structure: Raw IP Address Host
Credential Spoofing Trick via '@' character: http://google.com@attacker-controlled-host.com/login Browser navigates to: attacker-controlled-host.com
Dangerous File/TLD Variant (.zip domain): http://microsoft-update-installer.zip/download TLD: High-risk .zip domain

Social Engineering
